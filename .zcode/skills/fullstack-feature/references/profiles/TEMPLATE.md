# 项目 profile 模板

复制本文件为 `references/profiles/<项目标识>.md`（如 `acme-portal.md`）并按目标项目填写；未涉及的章节整节删除，占位符全部替换，成品不得残留 `<...>` 与示例行。

项目 profile 是本 skill 工作流与目标项目之间的**术语映射层**：只把模板中的通用占位符翻译为本项目术语，并指向项目权威文档的对应章节；**不复述、不新增规范**，与项目文档冲突时以项目文档原文为准。仅当项目探测确认目标项目与本文件「匹配条件」相符时才加载。

- <项目探测依据：仓库标识文件、模块命名、AGENTS.md/README 中的项目名、目录结构特征等>

## 规范读取顺序

1. <项目根权威文档，如 AGENTS.md / CONTRIBUTING.md / README>

3. <相邻实现与既有任务文档目录（含项目自有任务类型体系，如有）>
