# 设计系统 · AI agent 参考规则

> 本文件用于指导 AI agent / 开发者，不是前端运行时配置。
> 目标项目代码不得从 `$FRONTEND_ROOT/design-system/` import 或 @import。

## R0 参考与代码边界

- `design-system/` 只存参考资料，不是组件包，不是 npm 依赖；
- `design-system/ui/` 是参考实现或参考说明；目标项目使用时必须复制到项目自己的组件目录后再适配；
- 不建立指向 `design-system/` 的路径别名、包依赖或运行时引入；
- 目标项目已有规范、相邻代码和实际构建配置优先于本文件。

## R1 组件复用

- 开发新页面前先查目标项目已有组件和 [design-system.md](./design-system.md)；
- 优先复用现有组件，不重复创建等价组件；
- 新组件只有在现有能力无法满足且需求已确认时才创建；
- 新增、删除或修改组件后同步更新组件清单；
- 外部 UI 库遵循目标项目现有封装方式，不复制第三方源码。

## R2 Token 与样式

- 优先使用 [tokens.md](./tokens.md) 中已确认的项目 Token；
- 颜色、间距、字号、圆角、阴影、层级和动效遵循目标项目已有样式体系；
- 项目没有 Token 体系时标记为“未识别”，不要擅自重构全局样式；
- 不把本目录中的参考值当作目标项目可直接复制的硬编码值。

## R3 文档同步

- 组件用途、Props、Emits、Slots 或使用禁忌变化时同步更新 `design-system.md`；
- Token 命名或来源变化时同步更新 `tokens.md`；
- 规则变化时同步更新本文件；
- 文档只能记录已从项目读取到的事实，未知内容明确标记 `unknown` 或“未识别”。

## R4 验证边界

- design-system 生成后确认目标前端源码没有新增指向本目录的 import；
- 不因为生成参考资料而修改业务代码、package.json、构建配置或依赖；
- 后续功能开发仍使用目标项目自己的组件、样式和验证命令。
