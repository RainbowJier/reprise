# 前端体验改造 · 场景知识库

## 目标与边界

将后台式页面改为可探索、可阅读、可操作的工程场景知识库。首页展示场景集合；场景内保持「技术文档 / 交互演示」双入口。保留登录保护、认证 API、秒杀规则及现有未提交业务改动，不新增数据库变更或依赖。

技术事实：Vue 3 + Vite 8 + Tailwind v4 + vue-router + Pinia；marked 渲染仓库可信 Markdown，文档源仍为各场景 design.md。前端无现成 lint/test 脚本，验收采用 npm run build 和浏览器实际操作。现有 design-system 作为只读历史参考，不从该目录运行时导入；本次样式事实以 src/style.css 为准。

## 设计决策

- 暖白纸面、低饱和松绿、石墨文字，细边框与充足留白，避免后台高密度视觉。
- 桌面侧栏与顶栏固定，移动端抽屉导航，保留所有已规划场景。
- 场景总览支持名称/关键词搜索、状态筛选及明确空状态。
- 同场景文档与演示共用标题、简介和标签，减少重复标题。
- Markdown 保持内容源不变，加入稳定章节锚点、右侧目录、窄屏目录、阅读进度、代码复制反馈和表格横向滚动。
- 登录/注册独立页面统一品牌语言；认证演示调用现有健康检查及受保护用户接口，不展示令牌。
- 秒杀演示保留真实请求逻辑，优化商品、实验控制台、结果及空/错/加载态；重置前显式确认其会清空订单。
