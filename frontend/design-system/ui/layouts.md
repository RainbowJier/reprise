# UI · 布局与响应式

> 以下均为当前源码事实，不是待实施的线框图。断点采用 Tailwind 默认：sm 640、md 768、lg 1024、xl 1280px（根字号 16px 时）。

## 1. 场景知识库骨架

来源：[AdminLayout.vue](../../src/layouts/AdminLayout.vue)。

```text
桌面 ≥ lg
┌────────────────────── 顶栏 72px ──────────────────────┐
│ 品牌 / 全局说明                         场景集合 / 账号 │
├─────────────┬────────────────────────────────────────┤
│ 侧栏 256px  │ 主内容：最大 1120px，居中                │
│ 场景总览    │ 首页，或场景标题 / 文档-演示导航 / 内容  │
│ 已收录      │                                        │
│ 探索路线    │                                        │
│ 收录进度    │ 页脚                                   │
└─────────────┴────────────────────────────────────────┘
外框最大 1600px

手机 < lg
┌──────── 菜单 / 品牌 / 账号 ────────┐
│ 全宽主内容                         │
│ 点击菜单显示 272px 抽屉及背景遮罩   │
└───────────────────────────────────┘
```

### 尺寸与滚动

| 部分 | 基础值 | 响应式变化 |
| --- | --- | --- |
| 顶栏 | sticky top 0、h-18、px-5 | lg:px-8 |
| 侧栏 | fixed、宽 272px、p-5；默认不显示 | lg 起 sticky top 72px、宽 256px、px-6 py-8 |
| 侧栏高度 | 移动端 inset-y-0 | lg 高度为 viewport 减 72px |
| 目录列表 | min-h-0、flex-1、overflow-y-auto | 保持可独立滚动 |
| 主区 | min-w-0、px-5 py-8 | sm:px-8；lg:px-10 py-10；xl:px-14 |
| 标题区 | mb-8，h1 30px | sm 起 36px |
| 标题描述 | max-w-2xl、14px、行高 28px | 不铺满宽屏 |
| 页脚 | mt-16、border-t、py-6、11px | flex-wrap 避免拥挤 |

页面使用文档级滚动，不是固定高度主面板的内部滚动。侧栏单独滚动，不能把整个页面再包一层 h-screen overflow-hidden。

## 3. 场景集合首页

来源：[HomeView.vue](../../src/views/HomeView.vue)。

### Hero

- 默认单列，底部分隔线；xl 起两列，右侧方法栏固定 240px，列间 gap-8。
- 主标题 `text-3xl sm:text-5xl leading-[1.4]`，第二句使用 font-display 和主色。
- 简介 max-w-xl、text-sm、leading-7。
- 主入口为实心松绿按钮，次入口是页内锚点。
- 方法栏为静态说明，只有 xl 起可见，不是可点击步骤导航。

### 搜索与集合

- 标题和搜索框 flex-wrap；搜索默认全宽，sm 起 240px。
- 状态筛选按钮按内容宽度排列，可换行；数量是全集各状态数量。
- 卡片默认 1 列，sm 起 2 列，gap-4。
- 卡片 p-5、sm:p-6，flex-col，标签/动作区靠底保持对齐。
- 当前已收录优先排序；规划项无操作链接但说明仍正常可读，不靠极低透明度隐藏。
- 空态用虚线边框、大留白和清除按钮，没有假卡片或加载数据。

## 4. 技术文档页

来源：[DocView.vue](../../src/views/scenario/DocView.vue)、[renderDoc.js](../../src/utils/renderDoc.js)。

```text
< xl：阅读元信息 → 原生折叠目录 → 正文
≥ xl：阅读元信息
       正文 minmax(0,1fr) | 目录 176px
                          sticky top 104px
```

- 主网格 gap-9＝36px，内容顶端对齐。
- 目录的 sticky 设置在 grid 子项本身；只放在一个同高内层容器上会失去滚动粘附范围。
- 目录 max-height 为 viewport 减 128px，可纵向滚动。
- 正文无额外巨大白色外卡，使用 `prose prose-sm max-w-none min-w-0 break-words`。
- 正文/列表 28px 行高，h2 20px，h3 16px；h2 通过上分隔线与间距分章。
- 图片使用全宽、居中、轻边框和白底；原始图仍通过静态资源映射提供。
- 表格最小 480px，外壳 overflow-x-auto；代码块同样内部横向滚动。
- 移动目录为 details/summary，不是浮层；展开后 sm 起链接可排两列。
- 复制反馈固定底部 24px、最大 90vw，不改变正文布局。

不把桌面目录放进侧栏，也不靠全局横向裁切掩盖表格宽度。

## 5. 登录与注册外框

来源：[AuthShell.vue](../../src/components/AuthShell.vue)。

| 部分 | 默认 | 响应式 |
| --- | --- | --- |
| 页面 | min-h-dvh，居中，px-5 py-8 | sm:py-12 |
| 外框 | w-full max-w-5xl，rounded-2xl，边框，overflow-hidden | md 起两等分列 |
| 品牌区 | 隐藏 | md 起显示，bg-primary，p-10 |
| 表单区 | p-7 | sm:p-10，lg:p-12 |
| 品牌入口 | 表单区顶部显示 | md 起切换为左侧品牌链接 |

标题/副标题由 AuthShell 提供，表单由默认 slot 提供。小屏不是缩小整个桌面外框，而是移除品牌侧栏并保留完整控件宽度。

## 7. 秒杀演示

来源：[FlashSaleView.vue](../../src/views/scenario/FlashSaleView.vue)。

- 三层防线说明默认纵向，sm 起三列。
- 商品、实验室、订单为连续纵向板块，p-5、sm:p-6。
- 商品网格 md 起两列；初始 skeleton 则 sm 起两列，两者并非同一断点。

- 危险重置确认在控件区下方内联显示，不是独立 overlay。

## 8. 新页面检查清单（开发约定）

- 390px 手机、768px 中间宽度、至少 1280px 桌面检查列数与导航切换。
- 长标题、长用户名、表格、代码、加载/空/错状态均不应造成全页横向溢出。
- 正文 max-width 与 min-w-0 共同使用；固定目录宽度不挤压手机正文。
- 不新增重复 h1、深层外卡或第三套场景入口。
- 断点采用项目默认，特殊尺寸需能从实际内容说明理由。
